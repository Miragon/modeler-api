# __DISPLAY_NAME__ Modeler for VS Code

View and edit __DISPLAY_NAME__ diagrams as a canvas, backed by plain-text `.__EXT__` files: the
file stays the source of truth, so dirty state, saving, Git, diff and undo work as for any text
file. Open the source to the side and both stay in sync.

Create a diagram with **File → New File… → __DISPLAY_NAME__ Diagram**.
