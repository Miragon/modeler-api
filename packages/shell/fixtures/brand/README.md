# Brand fixture

`miragon-komet-blau.svg`, the official Miragon icon (green Komet on the blue tile), vendored unchanged
from `Miragon/corporate-identity` (`docs/public/logo/miragon-komet-blau.svg`, design system 1.13.0) for
the web demo's empty-state card (guide §2, §8, §11). Never edit it by hand: re-copy it from the source.

The shell package itself ships no brand asset; a web app vendors its own copy and passes its URL as
`emptyState.komet`.
